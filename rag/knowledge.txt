【SAGBI AGI プロジェクト概要】
SAGBI (Spirit AGent Bomb Infrastructure) AGI は、ユーザーの余剰計算リソースを統合し、巨大な知能を構築する分散型AGIプラットフォームです。
主な機能：
- 3Dアバターによるインタラクティブなチャット
- マルチモーダル（画像認識）対応
- ローカルRAGによるプライベートな知識の活用
- 分散コンピューティングによる推論の高速化

【Usage / 使い方】
- Start: Run `./start_sagbi.sh` / `./start_sagbi.sh` を実行して開始。
- Mobile: Scan terminal QR code / ターミナルのQRコードをスキャンしてスマホで参加。
- Sync: All messages are shared across devices / 全てのメッセージはデバイス間で共有されます。
- Privacy: Do not put sensitive info in RAG folders / RAGフォルダに個人情報を入れないでください。
